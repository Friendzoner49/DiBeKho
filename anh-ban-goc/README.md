# Ảnh bản gốc (Python 0.6.2) để so bản Swift

Chụp bằng `tools/chup_ban_goc.py` từ đúng code giao diện của bản Python (kiểu Fusion như app thật), trên một cửa hàng
bịa ra; không có dữ liệu thật. Khi sửa giao diện Swift thì chỉ so với các ảnh ở đây. Bản Python đổi giao diện thì chạy
lại lệnh trong `tools/chup_ban_goc.py` và commit ảnh mới.

Số đầu tên file theo thứ tự trong app: 01–06 các trang của cửa sổ chính (06 = các tab Cài đặt), 07–12 cửa sổ mở từ
Tra cứu và Kiểm kê, 13–16 phiếu (chuyển hàng, dùng thử, xuất kho, hàng về), 17–22 cửa sổ chi tiết, 23–31 hộp thoại nhỏ, 32–37 hộp nhập Excel, khôi phục mặt hàng, kiểm kê từ web, chọn bản giữ (dữ liệu bịa).
Chữ `b`, `c`, `d` là cùng màn ở trạng thái khác (đang gõ, mở rộng…).
